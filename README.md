# EduPanel - School Diary System

A modern, professional school diary system built with HTML, CSS, and JavaScript for GitHub Pages.

## Features

- **Multi-role system**: Director, Teacher, Student, Parent
- **My Lesson**: Real-time lesson management with grades, attendance, praises, and remarks
- **Dashboard**: Role-specific dashboards with statistics
- **Grade Management**: Record and view grades with color coding
- **Attendance Tracking**: Track student attendance and absences
- **Praises & Remarks**: Positive feedback and behavior notes
- **LocalStorage Database**: All data stored in browser

## Installation

1. Extract the ZIP file
2. Open index.html in your browser
3. Click "Get Started" and login with demo credentials

## GitHub Pages Deployment

1. Create a GitHub repository
2. Upload all files
3. Go to Settings > Pages
4. Select "Deploy from a branch"
5. Choose main branch and save
6. Your site will be live at: https://username.github.io/edupanel
